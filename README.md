# ArcaneForged

## 📌 Overview

This mod adds a special third weapon upgrade for TEAM HORAY's <a href="https://store.steampowered.com/app/2436940/_/">Sephiria</a>.

For the third weapon upgrade, you can select another weapon and gain some of its abilities.

<img src="Images/example.png" width=100%>

You can check which abilities you will gain in the journal.

<img src="Images/journal.png" width=100%>

## 📥 Installation
1. Switch to the beta version of Sephiria's workshop
2. Subscribe to the mod at https://steamcommunity.com/sharedfiles/filedetails/?id=3829579287
3. Enable the mod on the Sephiria title screen.
